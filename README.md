# Systems Engineering

A collection of practical C++ projects focused on operating systems, computer networks, socket programming, and low-level systems engineering.

## Engineering Focus

- Linux system programming
- Process and resource management
- Multithreading and concurrency
- TCP/IP networking
- Socket programming
- Client-server architecture
- Inter-process communication

## Projects

### 1. C++ Process & Resource Monitor
A Linux-based utility to monitor processes and system resources.

### 2. Multi-Client TCP Server
A C++ server capable of handling multiple simultaneous client connections using socket programming.

- Implement core functionality independently.

- Test and benchmark implementations.
- Document architecture and engineering decisions.
